Workspaces

  • Create a workspace with a title
  • Open it to manage boards and members

Boards

  • Each board starts with default columns: To Do, In Progress, Done
  • Click a board to open the kanban view
  • Add custom columns with the + Add column button

Tasks

  • Add tasks from any column using the + Add task button
  • Edit title, description, column (status), and assignee
  • Set start and due dates for Gantt view
  • Task status = the column it belongs to
